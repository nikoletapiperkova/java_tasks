# java_tasks
A collection of tasks solved with JAVA

Part 1: Variables, Data Types, and Operators
1. The Greeting Bot Create a program that stores your name in a String variable and your age in an int variable. Use System.out.println() to print: "Hello, my name is [name] and I am [age] years old."

2. Temperature Converter Create a program that converts a temperature from Fahrenheit to Celsius. Store the Fahrenheit value as a double. Formula: Celsius = (Fahrenheit - 32) * 5/9.

3. The Area Calculator Declare two int variables, length and width. Calculate the area of a rectangle and store it in a variable called area. Print the result with a descriptive message.

Part 2: Control Structures (If...Else & Loops)
4. Odd or Even? Write a program that uses an if...else statement to check if a number (stored in a variable) is even or odd. Use the modulo operator (%).

5. The Multiplier Use a for loop to print the multiplication table of 5 (from 5 x 1 to 5 x 10).

6. Countdown Timer Use a while loop to print a countdown from 10 down to 1, followed by the message "Liftoff!".

7. Array Summation Create an array of 5 integers. Use a for-each loop to calculate the sum of all elements in the array and print the total.

Part 3: Java Methods
8. Simple Addition Method Create a static method named mySum that takes two int parameters and returns their sum. Call this method inside main and print the result.

9. Check Age Method Create a method called checkAge() that takes an int parameter.

If age is less than 18, print "Access denied".

If age is 18 or older, print "Access granted".

10. Method Overloading: Area Create two methods named plusMethod. One should take two int parameters and return their sum. The other should take two double parameters and return their sum. Test both in your main method.

11. The Min/Max Finder Write a method that takes three integers as parameters and returns the largest one. Use if...else logic inside the method.
